
#### **СИСТЕМА ПЕРЕДВИЖЕНИЯ**

- **Паркур:** Прыжки через препятствия, карабканье по уступам, скольжение под завалами
    
- **Взаимодействие с окружением:** Использование верёвок, лестниц, пролом слабых стен
    
- **Тактическое перемещение:** Спринт с ограничением выносливости
    
- **Транспорт:** Поезд как основное средство передвижения между локациями
    

#### **БОЕВАЯ СИСТЕМА**

- **Ближний бой:** Комбо-атаки, блокирование, увороты с потреблением выносливости
    
- **Стрельба:** Реалистичная баллистика и тряска
    
- **Тактические действия:** Прикрытие, подавление огнём, фланговые манёвры
    
- **Классовые способности:** Уникальные умения каждого из 6 классов 

#### **СБОР РЕСУРСОВ**

- **Поиск предметов:** Старая техника, обломки, груды
    
- **Добыча материалов:** Разборка объектов на компоненты, охота для пропитания
    
- **Особые ресурсы:** Редкие компоненты для улучшений, уникальные артефакты
    

#### **СИСТЕМА ВЫЖИВАНИЯ**

- **Показатели состояния:** Здоровье, выносливость, голод, жажда
    
- **Статусные эффекты:** Радиация, отравление, кровотечение
    
- **Психологическое состояние:** Паника, усталость, мораль группы
    

#### **КООПЕРАТИВНЫЕ МЕХАНИКИ**

- **Синхронизированные действия:** Одновременный взлом, подъём тяжелых объектов
    
- **Разделение ролей:** Специализация по классам при решении задач
    
- **Система возрождения:** Возможность реанимировать товарищей (тут надо подумать, учитывая наши капсулы возрождения)
    

#### **ПРОКАЧКА И РАЗВИТИЕ**

- **Система мутаций:** Древо способностей с постоянными улучшениями
    
- **Развитие поезда:** Улучшение вагонов, добавление новых функций (думаю можно добавить большее количество разных вагонов, как систему прокачки. Например один для выращивания культур, другой для сбора воды из воздуха. Вагоны будут иметь разный внешний вид, что добавит вайба)
    
- **Прогрессия классов:** Уникальные умения для каждой специализации
    

Все системы связаны между собой - успешный бой требует ресурсов, которые добываются исследованием, а эффективное исследование зависит от правильного развития персонажа и координации в команде.
