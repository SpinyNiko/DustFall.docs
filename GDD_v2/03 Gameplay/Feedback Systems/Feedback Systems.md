#### **🔊 ЗВУКОВАЯ СИСТЕМА**

- **Тактильный звук:** Разные тональности шагов (металл, гравий, вода)
    
- **Пространственный звук:** Точное определение направления выстрелов, криков мутантов
    
- **Голосовые подсказки:** Персонаж комментирует состояние ("Ранен!", "Кончаются патроны")
    
- **Музыкальные триггеры:** Напряженный саундтрек при обнаружении, спокойная музыка в безопасности
    

#### **👁️ ВИЗУАЛЬНЫЕ ЭФФЕКТЫ**

- **Экранные эффекты:**
    
    - Кровавые блики при получении урона
        
    - Искажение зрения при низком здоровье
        
    - Дрожание камеры при активации мутаций
        
- **Эффекты окружения:**
    
    - Мерцание фонарей при приближении угрозы
        
    - Кровавые следы, ведущие к секретам
        
    - Пар от дыхания в холодных биомах
        

#### **📊 ИНТЕРФЕЙС И HUD**

- **Минималистичный HUD:**
    
    - Постепенное исчезновение неполезных элементов
        
    - Контекстные подсказки только при необходимости
        
- **Система маркеров:**
    
    - Цветовая индикация угрозы (желтый - обнаружен, красный - атакуют)
        
    - Интуитивные иконки ресурсов
        

#### **🎯 СИСТЕМА ОЦЕНКИ ДЕЙСТВИЙ**

- **Визуальное подтверждение:**
    
    - Контрольные точки при успешном уклонении
        
    - Спецэффекты при критических попаданиях
        
    - Анимация "последнего вздоха" для врагов
        
- **Тактильная обратная связь:**
    
    - Удовлетворительная отдача оружия
        
    - Чувство "веса" при взаимодействии с объектами
        

#### **🧩 СИСТЕМА ПОДСКАЗОК**

- **Контекстные указатели:**
    
    - Мерцание важных объектов
        
    - Звуковые сигналы для скрытых угроз
        
    - Запахи (визуальные эффекты дыма, пара) для указания путей
        

#### **⚡ СИСТЕМА СОСТОЯНИЯ ПЕРСОНАЖА**

- **Визуальные индикаторы:**
    
    - Грязь и кровь на одежде
        
    - Изменение позы при усталости
        
    - Визуальные эффекты мутаций
        
- **Аудио-индикаторы:**
    
    - Учащенное дыхание при низкой выносливости
        
    - Сердцебиение при страхе/панике
        

Каждый элемент обратной связи тщательно синхронизирован с геймплейными событиями, создавая интуитивно понятный и эмоционально насыщенный игровой опыт.
